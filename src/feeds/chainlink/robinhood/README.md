# Chainlink feeds — Robinhood

Per-feed libraries with `FEED` (standard proxy) and `HEARTBEAT` (86400).

Equity tickers: market hours `us_equities_24/5`. `USDG_USD` is a crypto stablecoin price. `SYRUPUSDG_USDG` is a crypto exchange-rate feed (USDG per share), not a USD price.

Addresses: [doc/robinhood-chainlink-usd-feeds.md](../../../../doc/robinhood-chainlink-usd-feeds.md).
